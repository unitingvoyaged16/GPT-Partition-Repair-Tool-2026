A2: While primarily designed for GPT disks, the tool includes basic MBR repair features. For complex MBR issues, consider using dedicated MBR repair utilities.

**Q3: How long does the repair process take?**

**Q4: Is there a risk of data loss?**

**Q5: Does it support external hard drives?**
